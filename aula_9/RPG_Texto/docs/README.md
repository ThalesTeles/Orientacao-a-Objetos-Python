# RPG de Texto — Projeto Final

Este é o **esqueleto** do jogo: `jogo.py`, `combate.py` e `dados.py` já estão
prontos e funcionando. Seu trabalho é implementar as classes nos outros
arquivos, seguindo os comentários PROBLEMA / PERGUNTA / DICA em cada um:

1. `item.py` — classe `Item`
2. `personagem.py` — `PersonagemBase`, `Guerreiro`, `Mago`, `Arqueiro`
3. `monstro.py` — `Monstro` e `gerar_monstro()`
4. `sala.py` — classe `Sala`
5. `masmorra.py` — classe `Masmorra`

Depois de implementar cada arquivo, rode `python jogo.py` para testar.
A especificação completa (atributos, métodos, regras) está no arquivo
`especificacao.md`.

Ordem sugerida de implementação: `item.py` → `personagem.py` → `monstro.py`
→ `sala.py` → `masmorra.py`.
